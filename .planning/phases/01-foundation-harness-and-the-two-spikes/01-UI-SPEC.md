# Phase 1 - UI Design Contract

> Visual and interaction contract for the Phase 1 spike UI. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
> Scope: chat view (log, pills, minimal composer stub), browser panel chrome (tab strip, nav buttons, address bar, suggestions, Import Arc logins), placeholder left rail, one test overlay. The real shell is Phase 2; the theme editor is Phase 7. All tokens are CSS variables so those phases extend them without renaming.
> Provenance legend: [CTX] from 01-CONTEXT.md, [README] from the Rust EvaOS README (visual target), [auto] auto-selected default (unattended run, Isaac unavailable).

## Spacing Scale

Declared values (all multiples of 4). Override Mantine's default spacing (xs 10, sm 12, md 16, lg 20, xl 32) in `createTheme({ spacing })` so Mantine props (`p="md"`, `gap="sm"`) resolve to this scale:

| Token | CSS variable | Value | Usage |
|-------|--------------|-------|-------|
| xs | `--eva-space-xs` | 4px | Icon gaps, pill icon-to-label, tab dot spacing |
| sm | `--eva-space-sm` | 8px | Compact element spacing, tab strip item padding, toolbar gaps |
| md | `--eva-space-md` | 16px | Default message padding, composer padding, panel inner padding |
| lg | `--eva-space-lg` | 24px | Gap between message turns, placeholder rail padding |
| xl | `--eva-space-xl` | 32px | Empty-state vertical padding |
| 2xl | `--eva-space-2xl` | 48px | Reserved (Phase 2 layout) |
| 3xl | `--eva-space-3xl` | 64px | Reserved (Phase 2 layout) |

Exceptions:
- Pane geometry is not spacing and is declared as layout constants in `tokens.css` [README Layout]: left rail 272px default (placeholder, fixed in Phase 1, no resize grip); browser panel default 480px, min 320px, max 960px, resizable by dragging the divider (4px hit area widened to 8px with an invisible overlay); chat main min 480px; window min 760px wide by 720px tall (set on `BaseWindow` `minWidth`/`minHeight`). When the window is narrower than rail + main min + panel min, the rail collapses to 0 first (panel-first shrinking [README]).
- Browser chrome heights: tab strip 36px, address row 40px (Mantine control heights `sm` 36 and `md` 42 are not used; these two values are multiples of 4). Icon-only buttons in chrome are 28px square (`ActionIcon size={28}`), with a 36px minimum hit target via padding on the tab strip row.
- Composer stub minimum height 56px.
- Rule: a rect sent over IPC for the browser slot is integer-rounded (D-07); the slot `div` has no padding, border or margin so slot rect equals view bounds.

## Typography

Exactly 4 sizes and 2 weights. Base is 14px, matching the Rust app's scale (`BASE 14`, text steps xs 10 / sm 12 / md 16 / lg 20) [README src/scale.rs]. Set `fontSizes` in `createTheme` to these values and `html { font-size: 14px }` is NOT used (rem stays 16px); sizes are declared in px via `--eva-fz-*`.

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Body | 14px | 400 | 1.5 (21px) | Message text, address bar input, composer input, empty-state body |
| Label | 12px | 600 | 1.4 (rounded to 17px) | Tab titles, pills, badges, tool and thinking row labels, tooltips, timestamps |
| Heading | 16px | 600 | 1.2 (19px) | Panel section title, empty-state heading, test overlay title |
| Display | 20px | 600 | 1.2 (24px) | Placeholder rail wordmark "EvaOS" only |

- Weights: regular 400 and semibold 600 only. Never 500 or 700. Assistant message emphasis (`**bold**` arrives in Phase 5) is out of scope; plain text only.
- Code fences, tool rows and session ids use the monospace family at 12px weight 400, line height 1.5 (18px). This reuses the 12px size; it adds no fifth size.
- Thinking blocks: Body size, italic, color `--eva-text-dim` [README line ~335: gray italic].
- `white-space: pre-wrap; overflow-wrap: anywhere` on message bodies so whitespace is preserved [CTX D-19].

## Color

Dark scheme is the default [CTX D-20]. 60/30/10 split. Values are the app's own CSS variables mapped onto Mantine's `colors.dark` and `primaryColor: "eva"` (a 10-step ramp generated around the accent). Contrast values below meet WCAG AA (4.5:1 text, 3:1 UI).

| Role | Variable | Value (dark) | Usage |
|------|----------|--------------|-------|
| Dominant (60%) | `--eva-bg` | #17181c | Chat log background, window background behind views |
| Secondary (30%) | `--eva-surface` | #202228 | Left rail, browser chrome (tab strip and address row), composer, code fences, assistant tool rows |
| Surface raised | `--eva-surface-2` | #2a2d35 | Hovered rows, active tab, address input field, suggestions list, overlay card |
| Border | `--eva-border` | #34373f | 1px dividers between panes and chrome rows |
| Text | `--eva-text` | #e6e8ec | Body text (contrast on bg 14:1) |
| Text dim | `--eva-text-dim` | #9aa0ab | Thinking text, timestamps, inactive tab titles, placeholders (contrast on bg 6.6:1) |
| Accent (10%) | `--eva-accent` | #7c8cff | See reserved list below |
| Accent text on fill | `--eva-accent-fg` | #0b0c10 | Label on accent-filled pills |
| Success | `--eva-ok` | #4cc38a | Working dot on a chat tab, "loaded" check in proof harness HUD only |
| Warning | `--eva-warn` | #e5a54b | Not rendered in Phase 1 (reserved for needs approval in Phase 4) |
| Destructive | `--eva-danger` | #ef5b5b | Error banners and failed page load text; no destructive buttons exist in Phase 1 |

Accent reserved for (exhaustive):
1. Jump to latest pill fill border and text, and New reply pill fill.
2. Focus ring on address bar input and composer input (2px, `--eva-accent`).
3. Active browser tab's 2px top indicator line.
4. The loading progress bar under the address row while a page loads (2px).
5. The "Import Arc logins" button label is NOT accent (neutral default button); accent is not used for generic buttons.
6. Unread/streaming indicator dot next to the chat title in the main header.

Never accent: body text, links inside messages (use `--eva-text` underlined in Phase 5), icons in chrome, borders, hover states.

Light scheme: out of scope. Declare only the dark values now; Phase 7 adds `[data-mantine-color-scheme="light"]` overrides to the same variable names. Do not add light values in Phase 1.

## Layout and Visual Hierarchy

Window composition [CTX D-06, D-07, D-20]: the shell `WebContentsView` fills the `BaseWindow`; the React app renders three columns, left to right:

1. Placeholder left rail (272px): background `--eva-surface`, right border `--eva-border`. Top: wordmark "EvaOS" (Display). Below: a single dimmed Label line "Chats and tools arrive in a later update." Contains no interactive items except a Settings-free spike "Test overlay" `Button variant="subtle"` pinned to the bottom (needed for D-08 overlay proof). Decorative only otherwise.
2. Chat main (flex 1, min 480px): vertical stack of header (40px), message log (flex 1), composer stub (min 56px).
3. Browser panel (default 480px, 320 to 960px): vertical stack of tab strip (36px), address row (40px), a loading bar (2px, absolutely overlaid at the bottom edge of the address row), then the browser slot `div` (flex 1, `data-testid="browser-slot"`, background `--eva-bg`, no padding). The panel's left edge is a resize divider.

Focal point: the message log; the browser panel is the secondary focus. Chrome rows use `--eva-surface` so content surfaces read as the dominant `--eva-bg`.

### Chat header (40px)
Left: session title (Heading, single line, ellipsis) from the resumed session file (fixture or live); next to it the accent streaming dot (6px) while a turn is in progress. Right: Label-size muted text of the session file basename (monospace). No buttons in Phase 1.

### Message log [CTX D-18, D-19; README lines ~53, ~335]
- Virtualized with virtua `VList`; the scroll container is the log itself, `overflow-y: auto`, thin 8px scrollbar thumb `--eva-border`, hover `--eva-text-dim`.
- Row padding: 16px horizontal, 8px vertical inside a turn, 24px between turns. Max content width 760px, centered when main is wider.
- User message: right-aligned bubble, `--eva-surface-2` fill, 12px radius, max width 80% of the column, Body text.
- Assistant message: no bubble, full column width, Body text on `--eva-bg`. Streaming text replaces the in-progress text per `message_update` [CTX D-16]; no per-token animation, no typewriter effect, no layout animation. A 1px blinking caret is NOT rendered; the streaming dot in the header is the only indicator.
- Code fence: `--eva-surface` fill, 1px `--eva-border`, 8px radius, 8px 16px padding, monospace 12px, horizontal scroll, `white-space: pre`. No syntax highlighting in Phase 1.
- Thinking block: collapsed row by default. Row: chevron (14px) + Label "Thinking" in `--eva-text-dim`, 28px tall. Click toggles `Collapse`; expanded content is italic dim Body text. Honors `show_thinking` semantics later; in Phase 1 always rendered collapsed.
- Tool call row: collapsed row, `--eva-surface` fill, 1px `--eva-border`, 8px radius, 28px tall, left chevron, tool name in monospace Label, right-aligned status text ("running" or "done") in Label dim. Expanded shows arguments and result as preformatted monospace, max height 240px with its own scroll.
- Pin-to-bottom [CTX D-18, README]: while within 24px of the bottom the log follows output. Scrolling up beyond 24px releases the pin.
- Pills (bottom center of the log, 16px above the composer, `position: absolute`, 28px tall, 14px radius full pill, Label text, 8px 16px padding):
  - Jump to latest: shown when unpinned. Neutral `--eva-surface-2` fill, 1px accent border, accent text, down-arrow icon. Click scrolls to bottom (instant, no smooth scroll so frame budget measurement is clean) and re-pins.
  - New reply: replaces Jump to latest while unpinned AND output has arrived since release. Accent fill (`--eva-accent`), `--eva-accent-fg` text. Click behaves the same. Both pills never show at once.
  - Pills fade in over 120ms (opacity only). `prefers-reduced-motion`: no fade.

### Composer stub
Phase 1 proves resume and streaming, not composer parity (Phase 4). The stub: a `Textarea` (autosize 1 to 6 rows, Body text), a Send `ActionIcon` (28px), a Stop `ActionIcon` shown while a turn is in progress. Enter sends (`prompt`), Shift+Enter inserts a newline, Escape while focused and turn in progress sends `abort`. Disabled with placeholder copy while the transport is not connected. No attachments, model picker or slash menu.

### Browser panel chrome [README Side panel > Browser; CTX D-09, D-11]
- Tab strip (36px, `--eva-surface`): one tab per browser tab, each 28px high, min 96px max 200px wide, 8px horizontal padding, title (Label, single line ellipsis), close `x` (14px) shown on hover and on the active tab. Active tab: `--eva-surface-2` fill, 2px accent top line, `--eva-text` title. Inactive: transparent, `--eva-text-dim`. A page-loading spinner (Mantine `Loader size={12}`) replaces the favicon slot while loading; favicon is 14px when available. A `+` `ActionIcon` (28px) ends the strip (new tab). Overflow: horizontal scroll, no wrapping, no shrinking below min width. Middle-click closes a tab. Closing the last tab opens a new blank tab (never an empty strip). Links meant for a new window open as new tabs [README].
- Address row (40px, `--eva-surface`, 8px padding, 8px gaps): Back, Forward, Reload (becomes Stop while loading) `ActionIcon`s (28px, `variant="subtle"`, tooltip with label), then the address `TextInput` (flex 1, 28px tall, `--eva-surface-2` fill, 8px radius, Body text, Select-all on focus), then Copy link, Open in default browser, Import Arc logins (`IconCookie`) as `ActionIcon`s. Back and Forward are `disabled` (opacity 0.4, not focusable-skipped) per history state.
- Address resolution [CTX D-11]: `http(s)://` or host-like text navigates; a bare integer opens `http://127.0.0.1:<port>/`; anything else searches with the README default engine. Escape in the field reverts the text to the current page URL.
- Suggestions (up to 6, README): a list directly under the address row, width of the input, `--eva-surface-2` fill, 1px `--eva-border`, 8px radius, 8px vertical padding, rows 32px high (title Label weight 600 + URL Label dim, single line each side by side with ellipsis). Up and Down move the highlight (`--eva-border` fill), Enter opens the highlighted row or the typed text, Escape closes. While the list shows, the browser view is hidden via `useOccludeBrowser()` [CTX D-08] because a native view would cover it.
- Loading bar: 2px accent line indeterminate (Mantine `Progress` animated) at the bottom of the address row while `did-start-loading` until `did-stop-loading`.
- Failed load / blocked content: slot shows an in-renderer error card centered (occluding nothing; the view is hidden while this card shows). See Copywriting.
- Import Arc logins: runs only on explicit click, never on launch [CTX D-13]. Click opens a Mantine `Modal` confirmation (which also exercises the overlay stack) with the README caution; on confirm the button shows a `Loader` and is disabled until the import resolves; a `Notification` reports the count; the active page reloads.

### Overlays [CTX D-08]
Every Mantine `Modal`, `Menu`, `Popover` and the suggestions list calls `useOccludeBrowser()` while mounted. The Phase 1 test overlay (rail button "Test overlay") is a centered `Modal` (width 400px, 16px padding, Heading title, Body text, one Close button). While it is open the active browser view reports `visible=false`; on close it returns with identical bounds.

### Interaction states
- Hover: surface steps to `--eva-surface-2` (rows, tabs, ActionIcons). Pressed: no scale or shift.
- Focus-visible: 2px `--eva-accent` outline, 2px offset, on every focusable element in the shell. The chrome rows must be fully keyboard operable (Tab order: tabs, +, Back, Forward, Reload, address, Copy, Open, Import). The guest page receives focus only when the slot is clicked; app hotkeys in a guest are forwarded to the shell [CTX D-09].
- Motion: only the 120ms opacity fades (pills, suggestions, Collapse at 150ms height). No spring, slide or glow. All motion off under `prefers-reduced-motion`.
- Cursor: default everywhere except tabs, buttons, pills (pointer) and the divider (col-resize).
- Window drag region: the chat header row (`-webkit-app-region: drag`) with interactive children marked `no-drag`; traffic lights inset with a 72px left spacer in the placeholder rail wordmark row (`titleBarStyle: "hiddenInset"`) [auto].

## Copywriting Contract

No em dashes (U+2014) in any string, ever (D-04 lint enforces it). Use commas, colons or periods instead. Sentence case. No exclamation marks.

| Element | Copy |
|---------|------|
| Primary CTA (composer) | Send (icon button, `aria-label="Send message"`) |
| Primary CTA (browser) | Import Arc logins (button in confirmation Modal; tooltip on the cookie icon: "Import Arc logins") |
| Chat empty state heading | No messages yet |
| Chat empty state body | Resume a session to see its messages here. |
| Transport not connected (composer placeholder) | Session is not running. Resume it to send a message. |
| Composer placeholder (connected) | Message Eva |
| Streaming indicator (aria-label on header dot) | Eva is replying |
| Pill: unpinned | Jump to latest |
| Pill: output arrived | New reply |
| Thinking row label | Thinking |
| Tool row status | running / done / failed |
| Browser empty tab (new tab) heading | New tab |
| Browser empty tab body | Type a web address, a search, or a local port such as 3000. |
| Address bar placeholder | Search or enter address |
| Tooltips | Back, Forward, Reload, Stop, New tab, Close tab, Copy link, Open in default browser, Import Arc logins |
| Suggestions empty | (list not shown) |
| Page load error heading | This page could not be loaded |
| Page load error body | {host} did not respond or refused the connection. Check the address and try again. |
| Page load error action | Try again (button, reloads) |
| Chat transport error banner | The session ended unexpectedly. Output so far is kept. Resume the session to continue. |
| Frame gap error (seq gap, snapshot requested) | Reconnecting to the stream. (Label, dim, in header; clears on snapshot) |
| Single-writer refusal | This session is already open in another EvaOS window or pane. Close it there first. |
| Import confirm title | Import Arc logins |
| Import confirm body | Copies Arc's saved logins for the sites on your allowlist into this browser, then reloads the page. Imported cookies are stored unencrypted in this browser's profile, so keep banking and password managers off the list. |
| Import confirm buttons | Import logins / Cancel |
| Import success notification | Imported {n} logins. Reloading the page. |
| Import failure notification | Could not import Arc logins: {reason}. Check that Arc is installed and allow Keychain access, then try again. |
| Test overlay title / body / button | Test overlay / The browser view is hidden while this is open. / Close |
| Destructive confirmation | none in Phase 1 (no delete or irreversible actions are rendered; Import logins is confirmed but not destructive) |

Accessibility copy: every icon-only control has an `aria-label` equal to its tooltip text. Log region `role="log"` with `aria-live="off"` (virtualized streaming would be too chatty; the header dot carries the status).

## Extension Points for Phase 2 and Phase 7

- Phase 2 replaces the three-column frame and keeps chat and browser components; the rail becomes the real sidebar (272px, 200 to 420 resizable). Keep pane widths in the layout constants named above so the swap changes only the frame.
- Phase 7 theme editor overrides `--eva-*` variables and the Mantine `colors`. Components must not use raw hex. The light scheme adds values under `[data-mantine-color-scheme="light"]` with the same names.
- Mantine `Modal`, `Drawer`, `Menu`, `Popover` wrappers that call `useOccludeBrowser()` arrive in Phase 2; Phase 1 wires it only for the test overlay, the suggestions list and the import confirmation.
