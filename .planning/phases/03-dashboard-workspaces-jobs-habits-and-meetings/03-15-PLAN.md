## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-51 | Tampering | argument injection into habit-gate | mitigate | typed actions, gateArgs refusals of leading '-', argv arrays, no shell |
| T-03-52 | Tampering | renderer supplying an arbitrary photo path to the CLI | mitigate | done takes a single-use main-issued token only; path never comes from the renderer |
| T-03-53 | Information disclosure | openPhoto on arbitrary files | mitigate | openPathChecked confines to env.habitPhotosDir with realpath and regular-file checks |
| T-03-54 | Denial of service | polling spawn storms or a hung CLI | mitigate | 4 s interval paused while hidden, single flight in renderer and main, 15 s timeout killing only that child |
| T-03-55 | Tampering | stale poll overwriting a command result | mitigate | generation counter and busy flag drop stale reads |
| T-03-56 | Information disclosure | tests touching ~/.config/eva | mitigate | non-live default is the fake gate with per-test state |
