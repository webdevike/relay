<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| renderer to main eva.todo.add | user text and a tag become a line in memory/todos.md |
| app to memory/todos.md | Eva (omp) edits the same file concurrently |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-35 | Tampering | markdown structure injection via todo text (newlines, fake headings) | mitigate | newlines collapsed to spaces before building the single row; text capped at 2000 chars; row prefix fixed by appendTodo |
| T-03-36 | Tampering | unknown or path-like tag | mitigate | contract regex plus knownTags check in main |
| T-03-37 | Tampering | clobbering a concurrent Eva edit or duplicate ids | mitigate | EvaFs.edit re-stat and hash check, retry once with fresh text, per-path queue |
| T-03-38 | Repudiation | silent failure | mitigate | inline role alert in the modal; nothing is written on refusal |
</threat_model>
