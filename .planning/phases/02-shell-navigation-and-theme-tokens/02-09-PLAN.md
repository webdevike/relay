<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| layout.json to tab model | Saved tabs may be hand-edited, oversized or point at unknown pages |
| tab titles to DOM | Titles derive from places (session names later) and render as text |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-09 | Tampering | malformed or oversized saved tabs | mitigate | loadTabs never throws, drops unknown pages, caps history at 50; contract caps list at 100 entries |
| T-02-34 | Denial of service | tab persistence writing on every state change | mitigate | 250 ms debounce plus unchanged-JSON check; main serialises writes (02-05) |
| T-02-35 | Tampering / XSS | tab titles rendered from place data | mitigate | titles rendered as React text children only, never as HTML; tooltips take strings |
| T-02-36 | Repudiation / data loss | Cmd+W closing a tab with a live chat | accept | closing a tab never stops a chat (Phase 1 keeps the session singleton); no data is deleted |
</threat_model>
