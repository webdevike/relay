<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| guest page to shell | Guest views forward key chords through main; page content must never trigger app actions beyond the allow-listed chord set |
| renderer to main | Quit-guard replies carry labels and ids typed by Zod |
| shell DOM events | The router sees every keystroke, including secrets typed in inputs |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-23 | Spoofing | guest page forging app chords | mitigate | main forwards only chords in FORWARD_FROM_GUEST from real before-input-event input; guest views have no preload so cannot call app.hotkey themselves |
| T-02-24 | Information disclosure | router handling keystrokes | mitigate | router acts only on cmd/ctrl/alt chords and Escape, never logs key text; e2e ring buffer stores chord and action ids only and exists only under EVAOS_E2E=1 |
| T-02-25 | Denial of service | Esc swallowed with nothing to dismiss, trapping xterm or inputs | mitigate | Esc is consumed only when the dismiss stack pops an entry |
| T-02-26 | Tampering | overlay bypass leaving the native view above a modal | mitigate | Vitest import scan fails any Mantine Modal, Menu, Popover or Drawer outside renderer/overlay |
| T-02-27 | Repudiation / data loss | quit with unsaved edits | mitigate | dirty registry feeds main's guard; failures keep the app open (D-18) |
</threat_model>
