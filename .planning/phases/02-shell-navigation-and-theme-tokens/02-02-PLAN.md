| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-04 | Tampering | layout.save / settings.save inputs | mitigate | `.strict()` Zod inputs, finite numbers, bounded arrays (back/forward max 50, list max 100), string max lengths |

| T-02-08 | Information disclosure | eva.sidebar output | accept | only counts and journal titles the user already sees in the Rust app; single-user local app |
</threat_model>
