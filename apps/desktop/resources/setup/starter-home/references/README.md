# References: stable facts and rules

Things that stay true for a while and that assistants look up on demand: people and how to write to them, accounts and which tool does what, house style, glossary of your own terms. One topic per file, named for the topic (for example a file called writing-style.md). Keep each file under about two pages; split by topic when it grows.

## Rules for this shelf
- Facts only, no task history (that goes in `memory/journal.md`).
- Never store passwords, keys or tokens here. They live in `secrets/`; name the file, not the value.
- A workspace card or runbook points here with a backticked path in its `## What to Load` table, so the file is read only when needed.
