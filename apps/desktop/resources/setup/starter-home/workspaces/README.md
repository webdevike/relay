# Workspaces: one card per project, client or area of life

A workspace card is the short page an assistant reads when a task starts: who or what this is, the standing rules, and a `## What to Load` table that names the next files to read. Cards stay small (about a page). Detail goes into `workspaces/<name>/<topic>.md` beside the card.

## Add one
1. Copy `.omp/templates/workspace.md` to `workspaces/<name>.md`.
2. Fill in the one-sentence description, the rules and the `## What to Load` table.
3. Mention the new card in `AGENTS.md` only if it changes where assistants should go first.
