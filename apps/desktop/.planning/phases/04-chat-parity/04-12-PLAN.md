## Phase Goal

**As a** EvaOS user, **I want to** manage and use all my omp chats from the new app (list, categories, composer, questions, subagents, shared writers, harness choice), **so that** my daily chat work runs here with the new-chat transport decided and recorded.

<objective>
Live list slice: the Chats list follows session file changes within 500 ms and shows live status rows.

Purpose: CHTP-05 and the status-row half of CHTP-01. Research Pitfall 1: FSEvents misses appends to files omp holds open, so the Rust app polls; here a narrow fs-event watch on the sessions dir plus a fast stat poll of recently active files keeps the 500 ms budget without polling thousands of files.
Output: ChatWatch, live status in list rows, listChanged subscription, e2e with measured latency.
</objective>
