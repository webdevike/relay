## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-47 | Tampering | frontmatter injection through duration fields (newlines, '---') | mitigate | duration fields validated against the runner regex before save; main re-validates; JobDoc writes single lines |
| T-03-48 | Tampering | silent overwrite of external edits | mitigate | basis captured at open; changed-on-disk banner; Save disabled until the user chooses |
| T-03-49 | Information disclosure | Open last session pointing outside the sessions dir | mitigate | chat.open enforces outside-sessions-dir in main (Phase 1); main only surfaces existing files |
| T-03-50 | Repudiation / data loss | destructive delete | mitigate | inline confirmation with Keep focused by default; run history kept |
</threat_model>
