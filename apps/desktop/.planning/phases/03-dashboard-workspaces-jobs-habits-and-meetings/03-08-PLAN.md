## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-24 | Tampering / Elevation | write channels taking paths | mitigate | inputs carry ids, names, stems and photo tokens only, all regex-bound and length-capped; main resolves paths |
| T-03-25 | Denial of service | oversized payloads | mitigate | max lengths and array caps on every output; outputs validated in dev and test by handle() |
| T-03-26 | Tampering | malformed CLI status | mitigate | lenient GateStatusSchema with defaults; unknown keys ignored |
| T-03-27 | Spoofing | non-app frames calling channels | mitigate | existing handle() isAppUrl sender check applies to every channel automatically |
</threat_model>
