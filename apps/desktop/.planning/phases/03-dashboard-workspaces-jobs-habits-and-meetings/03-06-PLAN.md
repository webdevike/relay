## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-19 | Tampering | CLI flag injection through names or reasons | mitigate | gateArgs refuses text starting with '-', NUL bytes and over-long text; habit edit uses --name=X; argv arrays only |
| T-03-20 | Information disclosure | notes path in a meeting record pointing at arbitrary files | mitigate | readNotes accepts only absolute .md regular files; open-in-default-app adds realpath checks in 03-17 |
| T-03-21 | Tampering | status edit dropping unknown fields | mitigate | parse, mutate one field, stringify in insertion order; tests compare parsed values and key order |
| T-03-22 | Tampering (XSS) | transcript and summary text | mitigate | parser returns plain strings; UI renders text children only |
</threat_model>
