<interfaces>
Rust model (tabs.rs lines 36-220, 221-256, 283-470, 492-570), to port semantically:
- HISTORY = 50. Place { page, chat: Option<Selected>, settings_section: Section (default Theme), meeting: Option<String> }. Place::page(p) sets chat = Draft only when p == Chat.
- same_place: different page -> false; Chat: either Draft -> false, else same chat (TS: string equality of session path); Settings: same section; Meetings: same meeting; others true.
- Tab { id, here, back, forward, pinned }. Tabs::new sorts pinned first (stable) keeping the active tab by id; next_id = max(id)+1.
- next_slot = max(active + 1, pinnedCount).
- arrive(here): fresh = take(fresh); left = previous place if != here. If fresh or left: find another tab (not active) showing same_place(here). If found: set its here; if fresh remove the active (just-forked) tab and fix the index; else restore the active tab's here to `left`; activate found; done. Else if left and active tab is pinned: restore pinned tab's here to left, insert a new tab(here) at next_slot, activate it. Otherwise: push left onto back (cap 50, drop oldest), clear forward, set here.
- open_tab (cmd-click fork): insert a copy of the current place as a new tab at next_slot, activate, set fresh = true; the following navigation lands in it (and if that place is open elsewhere, the fresh tab is dropped and the other is activated).
- open_new (+ and cmd+T): push a tab with Place::page(Chat) (draft) at the END of the list and activate it.
- close(ix): remove; if list empty -> per D-07 push a Dashboard tab (Rust uses a new chat; CONTEXT D-07 locks Dashboard); if ix < active then active -= 1; if ix == active then active = min(ix, len-1).
- close_active: no-op when active is pinned. close_others(ix): keep pinned and ix, activate ix. set_pinned(ix, p): remove, set, insert at pinnedCount (after existing pinned when pinning; at the start of unpinned when unpinning), keep the active tab by id.
- step(back): pop from back (or forward); if none no-op; push current here onto the other stack (capped); set here to the popped place.
- Saved place JSON: { "page": pageKey, "chat": <path> | "draft" | null (null/absent when page != chat), "settings_section": "Theme"|"Chat"|"Notifications", "meeting": string|null }. place_from: page must parse (unknown page -> drop that place); chat page: string other than "draft" -> path, else draft; settings_section label not one of the three -> "Theme"; meeting string or null.
- load: list entries without a parseable here are dropped; back/forward drop unparseable entries; pinned defaults false; empty list -> one Dashboard tab; active = saved active (default 0) clamped.
</interfaces>
