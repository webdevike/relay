<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| renderer to main IPC | Shell renderer sends widths, tabs, appearance, color, settings and quit-guard replies; handle() validates sender frame and Zod input |
| guest browser pages to main | Guest views have no preload and must never reach app channels |
| config dir on disk | layout.json, theme.json and settings.json are user-editable and may be malformed |
| Eva checkout | Read-only source for eva.sidebar |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-05 | Denial of service | layout/theme/settings writes | mitigate | one serialised write queue whose chain survives rejections; widths written only on pointer-up by the renderer |
| T-02-06 | Tampering | malformed layout.json, theme.json, settings.json | mitigate | tolerant parsers with defaults and clamping (readLayoutText, parseThemeDoc), reset flag for the toast, unknown keys preserved |
| T-02-07 | Spoofing | app.unsavedEdits.reply and app.saveDirty.reply forged by a guest page | mitigate | handle() sender-frame check plus random request ids that must match a pending entry |
| T-02-08 | Denial of service | hung renderer traps window close or quit | mitigate | 2 s timeout on the unsaved-edits request treats it as nothing dirty; approved flag prevents loops |
| T-02-20 | Tampering | app.setBackground color injection | mitigate | contract regex #rrggbb enforced by Zod before the handler runs; value only reaches setBackgroundColor and a JSON string |
| T-02-21 | Information disclosure / Tampering | eva.sidebar reading the Eva checkout | accept | read-only readers, no write API used, write guard stays installed (CLAUDE.md boundary) |
| T-02-22 | Tampering | config file names | mitigate | all access through ConfigStore.checkName; file names are literals, never renderer input |
</threat_model>
