<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| renderer to layout.json via main | Widths come from pointer math and keyboard steps; main clamps again |
| native browser view vs shell DOM | The native view sits above DOM and swallows pointer events during drags |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-30 | Denial of service | per-frame layout writes or runaway drag spamming disk | mitigate | previewWidth never calls IPC; commitWidth only on pointer-up, reset and keypress; main clamps and serialises (02-05) |
| T-02-31 | Tampering | oversized or NaN widths | mitigate | all widths pass through fit and shell-core clamps; contract requires finite numbers |
| T-02-32 | Spoofing / UX | native view covering the Grip so drags drop | mitigate | useOccludeBrowser while dragging hides the native view |
| T-02-33 | Information disclosure | e2e hooks used in tests | accept | hooks gated by EVAOS_E2E |
</threat_model>
